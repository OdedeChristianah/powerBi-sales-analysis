# powerBi-sales-analysis
sales data analysis and interactive dashboard created using Microsoft Power BI
Obejective: Analyze sales performance, revenue, cost and profitability.
KPIs: Total revenue, Total cost, Total profit, Numbers of customers and Number of Sales.
Analysis: Sales by Region, Sales by Product, Customer Analysis,Revenue trends and Profitability.
Key Insights: The dashboard was used to identify important patterns and trends in sales performance and customer activity.
Project Gaol: The goal of this project was to demonstrate my ability to clean, analyze, visualize and communication insights from business data using power BI
